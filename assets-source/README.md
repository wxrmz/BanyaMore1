# Исходники фотографий

Здесь лежат оригиналы снимков в полном разрешении — те, из которых собираются
файлы в `public/images`.

Зачем это нужно: в `public/images` картинки уже уменьшены и сжаты под сайт.
Пересобрать из них версию побольше или получше невозможно — детали, которых нет
в файле, не восстанавливаются. Однажды это уже стоило нескольких заходов:
оригинал первого экрана пришлось искать по телефонам и загрузкам, потому что в
проекте остались только ужатые копии.

## Что откуда

| Оригинал | Во что превращается |
|---|---|
| `hero-main-original.jpg` (4000×3000) | `public/images/hero-main.{avif,webp,jpg}`, `hero-mobile.{avif,webp}`, `public/images/20250721_204935.jpg` (галерея, «Домики на закате») |

## Правила

- Складывайте сюда оригинал **до** того, как уменьшать его для сайта.
- В архив для сервера эта папка не попадает — сайту она не нужна, только для
  пересборки картинок.
- Имя файла должно говорить, к чему он относится, а не быть номером с телефона.
